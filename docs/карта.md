# Автономная карта Ново-Переделкино

В браузере карта использует Leaflet 1.9.4 и файлы из `public/map-assets`. Интернет, ключи и регистрация для показа карты не нужны. Нажатие на значок открывает карточку заведения, на число — приближает группу. Если несколько заведений находятся в одной точке, на максимальном масштабе появляется список. Карту можно перемещать мышью и пальцем, увеличивать двойным нажатием, двумя пальцами или кнопками. Клавиатура поддерживает стрелки и клавиши «+» и «−». Кнопка со стрелкой запрашивает местоположение через браузер. Приложение использует координаты только для метки на устройстве.

## Данные и лицензии

В основу подложки вошли улицы, дома, парки, водоёмы, районы и станции метро из 81 векторного тайла z14. Снимок OpenFreeMap `20261115_080022_pt` получен 23 ноября 2026 года. Эти файлы покрывают район и его ближайшие окрестности для перемещения карты. Открытый фон и соседние географические подписи полезны для ориентации. Принадлежность заведений к каталогу определяет отдельный импорт административной границы. Метки появляются из того же отфильтрованного списка, что и карточки.

Авторство подложки — OpenFreeMap, © OpenMapTiles и © участники OpenStreetMap. Геоданные и производная база доступны по ODbL 1.0. Собранные SVG, подписи и геометрия границы находятся в открытом каталоге приложения `/map-assets/`. Источник, номер выпуска и диапазон координат записаны в `source.json`. Библиотека Leaflet распространяется под BSD-2-Clause, текст лицензии находится в `public/vendor/leaflet-LICENSE`. ## Обновление подложки в Windows

Подложка уже собрана. Для новой сборки выполните в PowerShell из корня проекта следующие команды. Потребуются Node.js 22 или новее и доступ в интернет.

```powershell
$build = Join-Path $env:TEMP 'gdeedim-map-build'
New-Item -ItemType Directory -Force -Path $build | Out-Null
npm.cmd install --ignore-scripts --prefix $build @mapbox/vector-tile@2.0.4 pbf@4.0.1
Copy-Item scripts/build-map.mjs -Destination $build
node (Join-Path $build 'build-map.mjs') public/map-assets
Copy-Item data/boundary.geojson public/map-assets/boundary.geojson
```

Скрипт запрашивает один тайл за раз со своим User-Agent. Размер разовой выгрузки ограничен 50 МБ. Для сверки исходной геометрии каждого тайла можно использовать его координаты и URL из `public/map-assets/source.json`.
