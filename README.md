# ГдеЕдим?

На GitHub Pages главная страница сохраняет гид по кофейням и коворкингам и установку на телефон. Кнопка «Столики и предложения» открывает каталог Ново-Переделкина с картой, поиском и избранным. Без подключения сервера доступны сведения из снимка OpenStreetMap.

## Полная версия

Из корня репозитория выполните `docker compose up --build`. На Windows с Node.js 24 и PostgreSQL 17 доступна команда `npm.cmd run local`.

На http://localhost:3000 открывается полная карта с избранным, кабинетами сотрудников и администратора, подтверждениями столиков и предложениями. Ссылка «Кофейни и коворкинги рядом» возвращает к исходному гиду. Отдельный учебный режим, первый администратор, миграции и проверки описаны в [инструкции по запуску](docs/запуск.md).

## Подключение к действующему сайту

Разместите серверную версию с PostgreSQL и HTTPS. Задайте публичный адрес приложения в окружении сервера по инструкции. Затем укажите тот же адрес в `site-config.js` и обновите GitHub Pages. Кнопка на прежней главной странице откроет полную версию. Ключи ЮKassa задаются только в окружении сервера. Избранное статического гида хранится в браузере на домене Pages.
