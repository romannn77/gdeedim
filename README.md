# ГдеЕдим? — новый дизайн v2

Полный статический сайт для GitHub Pages. Никакие сборки, npm, пароли или серверная установка не нужны.

## Как заменить существующий сайт
1. Сохраните копию старого репозитория: Code → Download ZIP.
2. Распакуйте этот архив на компьютере.
3. Откройте ваш существующий репозиторий gdeedim на github.com.
4. В корне репозитория выберите Add file → Upload files.
5. Перетащите ВСЁ СОДЕРЖИМОЕ распакованного архива, включая папку icons. Сам ZIP загружать не нужно. index.html должен остаться в корне репозитория, без дополнительной папки gdeedim-v2.
6. Сохраните изменения в той ветке, из которой публикуется сайт (обычно main). Если GitHub предлагает новую ветку, создайте и объедините pull request.
7. Проверьте Settings → Pages: Deploy from a branch, main, / (root). Если у вас другой источник публикации, используйте его.
8. Дождитесь успешного развёртывания в Actions / Pages и откройте прежнюю ссылку сайта.

Адрес останется прежним, если репозиторий не переименован. Замена файлов не меняет доступность репозитория. Если Pages уже открыт всем, сайт продолжит открываться по ссылке. Доступ только «знающим ссылку» не является защитой: обычный публичный сайт может найти любой человек.

Если виден старый дизайн: Ctrl+Shift+R на компьютере, на телефоне закройте и заново откройте страницу. Иконка ранее установленной PWA может сохраняться: удалите старый ярлык и заново добавьте приложение с обновлённого сайта.

## Что изменилось
- Кремовый фон, терракотовый акцент, редакционная типографика.
- Собственная SVG-иллюстрация с кофе и круассаном, без внешних фотографий.
- Новая иконка с тарелкой и столовыми приборами для сайта и PWA.
- На ПК каталог слева, карта справа. На телефоне карта над списком мест.
- Метки карты показывают категорию вместо демонстрационных процентов.
- Новые карточки с тематической иллюстративной полосой и заметной ссылкой на детали.
- Исправлены пути ресурсов и offline-экрана для GitHub Pages внутри /gdeedim/.

## Состав
index.html — интерфейс и логика карты, каталог places.
design.css — новая визуальная тема и мобильная адаптация.
table.svg — авторская иллюстрация.
pwa.js — установка и регистрация service worker.
sw.js — экран отсутствия подключения (карта офлайн недоступна).
manifest.webmanifest — параметры установленного приложения.
icons/ — SVG и PNG-иконки.

## Данные и ограничения
Три места сохранены из предыдущей версии: «Мы за кофе», «Эрме», коворкинг Дома творчества. Полного покрытия двух районов пока нет. Рестораны и кафе остаются планом развития.
Занятость — демонстрационные числа, не реальные измерения. Панель бизнеса меняет локальный вымышленный пример, а не общую базу. Геолокация запрашивается только после нажатия и используется в памяти текущей страницы. Расстояния по прямой.
Карта загружается из OpenFreeMap, библиотека MapLibre — с unpkg; нужен интернет. При недоступности карты остаётся список адресов. Данные внешних заведений не перепроверялись при смене дизайна.

## Проверка после публикации
Откройте сайт в приватном окне: проверьте карту, карточку, поиск, геолокацию, раздел демо и кнопку установки. Повторите на телефоне. Геолокация и PWA требуют HTTPS. В окружении подготовки проверены JavaScript, ресурсы, относительные пути, поиск и геолокационные сценарии с тестовыми координатами. Полная визуальная браузерная проверка не выполнена.
